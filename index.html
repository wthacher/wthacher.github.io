Bio

I am a PhD student at UC Berkeley in the Applied Science and Technology Group and I work at Lawrence Berkeley Lab in the Applied Numerical Algorithms Group. My research is focused on mathematical and computational aspects of numerical methods for solving partial differential equations.

In particular, I think there are a lot of interesting unanswered questions about high order accurate finite difference methods. My thesis is on proving discrete maximum principles for high order finite difference discretizations of the Laplace operator. Link to Draft

More recently, I have been spending time thinking about machine learning, and have worked on reinforcement learning approaches to mesh generation.

Code

  1. ellipticInterface - Solver for elliptic equations of the form $$\nabla \cdot (A \nabla u) - cu = f$$ with discontinuous coefficients and jump conditions. C++ code built on the Chombo library.
  2. RLMesh - Two dimensional triangular mesh generation algorithm based on graph neural networks trained using reinforcement learning. Python code built on Ray RLlib.
  3. TD3 - Implementation of the TD3 in RLlib as a minimal wrapper of SAC. Python code built on Ray RLlib.
